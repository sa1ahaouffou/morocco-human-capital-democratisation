# Figures

- [`facts/`](facts/) — 26 figures that report a measured quantity.
- [`models/`](models/) — 7 figures that report an estimate from a fitted model.

Nothing has been removed: the split only separates what is measured from what is
assumed, so the first can be cited without carrying the second. The classification,
with a one-line reason for each file, is in [`code/tiers.py`](../code/tiers.py).
